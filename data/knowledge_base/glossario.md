# Glossário de siglas

Tipo de documento: `glossario` · Origem: briefing/enunciado do Challenge e definições de engenharia de confiabilidade (conteúdo conceitual, sem dado da Motiva).

| Sigla | Significado |
|---|---|
| CFTV | Circuito Fechado de TV (câmeras de monitoramento) |
| PTZ | Pan-Tilt-Zoom: câmera com movimento horizontal, vertical e zoom |
| PMV | Painel de Mensagens Variáveis |
| Callbox | Totem de emergência com comunicação direta com o CCO |
| SAT | Analisador de Tráfego (sensores e radares de volume, velocidade e classificação) |
| SCA | Sistema Ambiental (estações meteorológicas) |
| WIM / HS WIM | Weigh-in-Motion: pesagem em movimento (alta velocidade) |
| OCR | Reconhecimento óptico de caracteres (leitura de placas) |
| CCO | Centro de Controle Operacional |
| ITS | Sistemas Inteligentes de Transporte |
| FSM | Field Service Management: sistema de gestão de ordens de serviço e histórico de falhas |
| OS | Ordem de Serviço |
| POP | Procedimento Operacional Padrão |
| PMP | Plano de Manutenção Preventiva |
| TAG | Identificador único de um ativo no catálogo |
| CBM | Condition-Based Maintenance: manutenção baseada na condição do ativo |
| RCM | Reliability-Centered Maintenance: manutenção centrada em confiabilidade |
| WCM | World Class Manufacturing |
| RGA | Reliability Growth Analysis: análise de crescimento de confiabilidade |
| LDA | Life Data Analysis: análise de dados de vida |
| λ (lambda) | Taxa de falha: número de falhas dividido pelas horas de operação |
| MTBF | Mean Time Between Failures: tempo médio entre falhas (1/λ no modelo exponencial) |
| MTTR | Mean Time To Repair: tempo médio de reparo |
| R(t) | Confiabilidade no tempo t; no modelo exponencial, R(t) = e^(−λt) |
| EPI | Equipamento de Proteção Individual |
| NR-10 | Norma Regulamentadora de segurança em instalações e serviços em eletricidade |
| NR-35 | Norma Regulamentadora de trabalho em altura |
| LGPD | Lei Geral de Proteção de Dados Pessoais (Lei 13.709/2018) |
| RAG | Retrieval-Augmented Generation: geração apoiada em recuperação de trechos da base |
| IR | Infravermelho |
